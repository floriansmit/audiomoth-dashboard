# Security Policy

## Reporting a Vulnerability

Please use GitHub's private **Report a vulnerability** option on the repository Security page when available. If private reporting is unavailable, open a brief issue asking for a private contact channel without including exploit details, credentials, private coordinates, or recordings.

Include the affected version or commit, operating system, reproduction steps, and likely impact. Please allow time for the report to be assessed before publishing technical details.

## Local Data

AudioMoth Dashboard is a local application, but it processes user-selected files and invokes third-party analyzers. Only open trusted projects and analyzer outputs. Keep field recordings, location data, generated databases, and API credentials out of Git; the standard local data locations are ignored by the repository.
